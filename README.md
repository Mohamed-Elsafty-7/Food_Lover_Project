# Food Lover — Restaurant Website

Food Lover is a restaurant-themed website designed to present a restaurant, showcase food, and organize information into clear sections.

## 🌐 Live Demo

[Visit Food Lover](https://mohamed-elsafty-7.github.io/Food_Lover_Project/)

## ✨ Features

- Restaurant landing page with a hero section.
- Navigation links for the main website sections.
- Restaurant introduction and history section.
- Food-related content and menu presentation.
- Image gallery.
- Contact information and working hours.
- Contact form interface.

## 🛠️ Built With

- HTML5
- CSS3
- Font Awesome 6

## 🚀 Run Locally

```bash
git clone https://github.com/Mohamed-Elsafty-7/Food_Lover_Project.git
```

Open `index.html` in your browser.

## 📚 What I Practiced

- Creating multi-section landing pages.
- Building layouts with CSS Flexbox.
- Working with background images and overlays.
- Styling navigation, buttons, and content sections.
- Using an external icon library.

## ⚠️ Current Limitations

The contact form is a front-end interface and is not connected to a back-end service for sending messages. Some page content and links may also need further refinement.

## 🔮 Possible Improvements

- Improve mobile navigation and responsive layouts.
- Connect the contact form to a suitable service.
- Replace placeholder content with finalized restaurant information.
- Improve form validation and accessibility.
